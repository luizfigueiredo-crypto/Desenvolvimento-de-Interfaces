# Desenvolvimento de Interfaces - JavaScript

## Sobre o projeto

Este repositório apresenta as atividades desenvolvidas durante as três aulas de JavaScript da disciplina de Desenvolvimento de Interfaces.

Durante as aulas, foram desenvolvidas páginas web e aplicações utilizando HTML, CSS e JavaScript, com o objetivo de praticar conceitos de programação, lógica e interação com o usuário.

## Aula 01 - Introdução ao HTML, CSS e JavaScript

Na primeira aula, foram desenvolvidas atividades introdutórias para conhecer a estrutura de uma página HTML e utilizar CSS e JavaScript.

**Atividades desenvolvidas:**

- Criação de uma página HTML com o tema "Café: uma paixão brasileira".
- Utilização de títulos, parágrafos, imagens, listas e links.
- Desenvolvimento de uma calculadora.
- Utilização de CSS para estilização da calculadora.
- Implementação das operações matemáticas com JavaScript.

## Aula 02 - Desenvolvimento com JavaScript

Na segunda aula, foram desenvolvidas atividades envolvendo interação com o usuário, validação de informações e utilização de condições em JavaScript.

**Atividades desenvolvidas:**

- Verificador de idade.
- Criação de páginas HTML.
- Utilização de campos de entrada de dados.
- Cálculo da média de três notas de um estudante.
- Classificação do aluno em aprovado, recuperação ou reprovado.
- Validação dos dados informados pelo usuário.

## Aula 03 - Calculadora com JavaScript

Na terceira aula, foi desenvolvido um projeto de calculadora utilizando HTML, CSS e JavaScript.

**Funcionalidades desenvolvidas:**

- Adição.
- Subtração.
- Multiplicação.
- Divisão.
- Porcentagem.
- Utilização de números decimais.
- Botão para limpar os valores.
- Função para apagar o último número.
- Utilização do teclado para realizar operações.
- Exibição do resultado e histórico da operação.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Objetivos de aprendizagem

- Compreender a estrutura de páginas HTML.
- Aprender a estilizar páginas utilizando CSS.
- Desenvolver a lógica de programação com JavaScript.
- Trabalhar com funções, variáveis e condições.
- Manipular elementos HTML utilizando JavaScript.
- Criar aplicações interativas.
